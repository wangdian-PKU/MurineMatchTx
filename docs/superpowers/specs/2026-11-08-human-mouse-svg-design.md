# 人与鼠实心简笔画 SVG 设计

## 目标

为科研图示提供两幅独立、易识别、可无损缩放的实心简笔画：一个正面人形和一个右向鼠形。

## 输出

- `figure/human_simple.svg`
- `figure/mouse_simple.svg`

两份文件均使用 `viewBox="0 0 512 512"`，不声明固定像素尺寸，以便调用方自由缩放。

## 视觉规格

### 人形

- 正面、中性成人形象。
- 由圆形头部和连贯的躯干、手臂、双腿组成。
- 采用纯黑实心几何轮廓，不包含五官、服饰、文字或边框。
- 四肢留有清楚间隙，保证缩小后仍能辨识。

### 鼠形

- 右向侧面轮廓。
- 包含圆润身体、尖圆口鼻、大耳、眼睛、四肢暗示和向后弯曲的长尾。
- 主体采用纯黑实心轮廓；眼睛使用小型留白形成对比。
- 不加入毛发纹理、颜色、文字或边框。

## SVG 约束

- 透明背景。
- 仅使用标准 SVG 几何元素与路径，不依赖字体、脚本、滤镜或外部资源。
- 使用整数或简洁小数坐标，保持源码可读、可继续编辑。
- 主体在画布四周保留安全边距，避免缩放或导出时裁切。

## 验收

1. 两个 SVG 均可通过 XML 解析。
2. 浏览器可正常渲染，背景透明且无外部依赖。
3. 人形与鼠形在缩小预览中仍能一眼辨识。
4. 文件路径、画布和视觉规格与本文一致。
